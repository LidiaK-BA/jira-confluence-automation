# Weekly Status Report Instructions

## Format
- Output Markdown only.
- Use exactly three sections, in this order, as `##` headings:
  1. `## Accomplishments`
  2. `## Blockers`
  3. `## Next Week`

## Content Rules
- Use bullet points only. No paragraphs, tables, or numbered lists.
- Keep the whole report to a maximum of 20 lines, including headings and blank lines.
- Write one short, factual statement per bullet.
- If a section has nothing to report, write a single bullet: `- None`.

## Tone and Style
- Use a professional, neutral tone.
- Use no fluff words (for example: "very", "really", "just", "amazing", "great", "basically", "hopefully").
- Use the past tense for accomplishments and the future tense for next week.
- State outcomes, owners, and dates where known.
